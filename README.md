#  PoseAI – AI Based Gym Form Correction System

PoseAI is a real-time computer vision based virtual fitness trainer that detects human posture during exercises, evaluates biomechanical joint angles, and provides corrective feedback using only a camera.

The system helps prevent injuries and improves workout efficiency without requiring expensive sensors or personal trainers.

#  Problem Statement
Many gym users perform exercises incorrectly due to lack of supervision, leading to injuries and ineffective workouts.  
Existing fitness apps only track repetitions or calories and do not analyze posture alignment.

PoseAI solves this by providing **real-time posture correction using AI and computer vision.**

---

#  Features
- Real-time human pose detection
- Joint angle calculation
- Squat repetition counter
- Posture accuracy tracking
- Visual corrective feedback
- Live performance chart dashboard
- Runs directly in browser (no installation)
- Works using only webcam

# Results
The system successfully detects incorrect posture such as:
- Knee misalignment
- Shallow squat depth
- Improper joint extension

Average detection accuracy: **~92%**
