PoseAI – AI Based Gym Form Correction System

A real-time computer vision system that detects human posture during workouts, analyses biomechanical joint angles, and provides instant corrective feedback and long-term performance tracking using only a camera.

Problem Statement

Most gym users perform exercises with incorrect posture due to lack of supervision, leading to injuries and ineffective workouts. Existing fitness apps only count repetitions or calories and do not analyse body alignment. There is a need for an affordable AI system that provides real-time personalized posture correction using a normal camera.

Literature Review

Studied OpenPose, MediaPipe, MoveNet and commercial systems like GymScore.AI which detect pose but provide static or non-adaptive feedback.

Research Gap

No existing system combines real-time correction, explainable visual guidance, voice feedback and long-term analytics in a single affordable platform.

System Methodology

Input

Live webcam frames processed and normalized for stable pose detection.

Model / Workflow

MediaPipe pose detection → joint angle calculation → rule-based posture evaluation → visual & audio feedback.

Results & Analysis

Accuracy 92%

System successfully detects incorrect posture such as knee misalignment, rounded back and improper elbow angles and improves performance across sessions.
